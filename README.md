# RITUAL – A Depiction of Atharv Bhagwat

RITUAL is a personalized rule-based AI chatbot developed in Python as part of the DecodeLabs Artificial Intelligence Internship Program.

Unlike a traditional chatbot, RITUAL is designed to reflect the personality, interests, likes, dislikes, hobbies, and opinions of Atharv Bhagwat. Through predefined responses and decision-making logic, the chatbot creates an interactive experience that allows users to learn more about Atharv through conversation.

## Features

- Interactive command-line chatbot
- Personalized responses based on Atharv Bhagwat's preferences
- Handles greetings and common conversations
- Supports multiple predefined questions and answers
- Case-insensitive input handling
- Input sanitization for better user experience
- Continuous conversation loop
- Exit command to end the conversation
- Fallback response for unknown queries

## Technologies Used

- Python 3
- Dictionaries
- Loops
- Conditional Statements
- String Manipulation

## Project Objective

The objective of this project is to understand the fundamentals of Artificial Intelligence through a Rule-Based Chatbot. The chatbot uses predefined rules and responses to simulate human conversation and demonstrate basic AI decision-making concepts.

- Who do you like?
- What is your favorite programming language?
- What is your dream?
- Bye

## How It Works

1. The chatbot receives user input.
2. The input is converted to lowercase and cleaned of extra spaces.
3. The chatbot searches for the input in its knowledge base (dictionary).
4. If a matching response is found, it is displayed.
5. If no match is found, a default response is returned.
6. The conversation continues until the user enters "exit".
